SeriesScope allows users to search and discover information about queried shows, actors, and directors.

The shows search allows users to both search for specific shows, and filter the results of the shows by genre. By clicking on one of thses shows, the user is presented with relevant information about this show, like episode count, airing status, cast, etc. Upon selecting a member of the cast, their screen is opened with their relevant information.

The people search only lets users search for people, but similarly to shows, users can see which shows that person has starred in, directed, and produced - these shows can be selected to view more information about them.
